韩语 SRT 字幕标注 v1.0.14

基于 Korean Web Annotator 的独立字幕版；v1.0.3 同步网页版 v1.1.14 的混种动词对齐修复。解压后，在 Chrome / Edge 扩展管理页启用开发者模式，选择“加载已解压的扩展程序”，选择含 manifest.json 的文件夹。

点击插件图标 → 打开字幕工作台 → 选择 .srt → 开始标注 → 下载标注 SRT。

首次使用：打开“词典 / API 设置”导入原程序支持的词典 ZIP / DB。此字幕版作为独立扩展安装时，需要重新导入词典并配置 API。无需 API 时可仅使用本地规则；模型审核、手动聊天审核、批次容量和流式开关沿用设置。

输出示例：경제는 → 經濟(경제)는；컴퓨터 → 컴퓨터(computer)；게임기는 → 게임(game)機(기)는。

双语字幕只分析韩语片段。保留序号、时间轴、其他语言、原换行和样式标签。SRT 内已有的常见原词括号标注会跳过，避免重复。输入支持 UTF-8、带 BOM 的 UTF-16、CP949/EUC-KR；自动识别不正确时手动选择。输出 UTF-8。

独立工作台打开期间可持续处理，支持停止、预览及下载部分已确认结果。手动模式可复制或下载每批提示词、粘贴或导入 JSON / TXT 答案，校验后继续；刷新/关闭工作台会中止当前任务，请在完成后下载。

词义选择沿用原词典与审核规则，未确定的词保留韩语。未附带词典数据。

本包只含运行文件、使用说明和第三方许可；不附带测试、历史验证记录或开发计划。

v1.0.13 更新：
把含汉字与固有语成分的整词词源纳入混种分段处理，支持原样保留的韩语前缀、中间成分及后缀。每个韩语锚点必须与原文相同，汉字仍须逐音节安全对齐；不猜测或删除需要保留的韩语。
